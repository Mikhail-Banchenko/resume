
Resume site (static)
--------------------

Files:
- index.html
- style.css
- CV(EN).pdf

How to deploy to GitHub Pages (quick):
1. Create a new GitHub repository (public).
2. In the project folder (this folder), run:
   git init
   git add .
   git commit -m "Initial resume site"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO.git
   git push -u origin main
3. On GitHub: Settings → Pages → set source to branch 'main' and folder '/ (root)'
   The site will be available at: https://USERNAME.github.io/REPO/

Feel free to edit index.html to change wording, colors, or add projects/links.
